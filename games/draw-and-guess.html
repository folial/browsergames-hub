Pixel Draw & Guess

A pass-and-play drawing game. Player 1 draws a secret word, then Player 2 guesses what it is.

Player 1: draw this wordScore: 0

How to play Pixel Draw & Guess

Player 1 receives a secret word and draws it on the shared canvas without saying the answer. Player 2 types a guess, then use “Done / Reveal” to check the round. Pass the device between turns and keep score informally for a longer party game.

Make the clue readable

Start with the biggest shape, then add one or two distinctive details. Simple drawings are easier to guess than tiny decoration. This is a local pass-and-play activity; it does not create a remote video call.
